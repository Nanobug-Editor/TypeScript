# TypeScript for Nanobug

[English](README.md)

独立 TypeScript 插件统一管理项目上下文和原生编译器工作进程。插件 0.1.15 正式支持已验证的 Windows x86-64、TypeScript 5.9.3、Node 24.19.0 组合，并通过独立 Vue 插件支持 Vue 2.6.14、2.7.16 和 3.5.22；Vue 范围限于 26 个已声明适用写法组合及其固定依赖。它保留原生服务 0.1.14 归档的完整字节，SHA-256 为 `71c2794f0833bb548d365255878362b4637750bdac05e7ff7e8392df73884f83`；插件与原生工具独立版本化。选定的配置根或推断源文件目录拥有独立宿主连接生命周期；共享源快照仍以原始工作区为访问边界。此功能支持声明不表示创建 Release 或上架市场。

未改变的原生闭包已通过源码 48 项、密封工具 48 项测试，均无跳过。固定历史写法及外部脚本的原生编辑场景保留原始包身份。宿主已实际通过 S4 冲突拒绝/恢复（280.28s）、S5 outer 更新/恢复（164.27s）、Worker 撤权/正向更新（67.94s/67.84s），以及使用 .15/.12 待提升支持元数据候选的三版本暖缓存 S1 场景（97.62s）。这些均为保留的实际运行，不冒充支持标签重建后的新测试。

普通 Windows 桌面已观察七项语言操作、补全 resolve 联合导入及一次 Undo、跨文件预览/取消/应用/整组 Undo、项目选择与本机偏好持久化、真实中文输入法候选/提交/取消/Undo、滚动和字号变化。暖缓存悬浮、深浅主题正文/行内代码/代码片段，以及 Ctrl+I → Escape → Ctrl+I 重开均有实际回归及桌面证据。范围、输入身份和已知访问性退役限制见宿主[桌面验收](https://github.com/Nanobug-Editor/Editor/blob/main/docs/plugins/verification/vue-typescript-desktop-2026-10-20.md)。精确归档身份及 Package/Manager policy、双包结果由宿主[交付收据](https://github.com/Nanobug-Editor/Editor/blob/main/docs/plugins/verification/vue-typescript-remaining-delivery-2026-10-20.md)独立跟踪；本元数据不声称某个 ZIP 已完成测试。

适配契约 1.1 支持显式请求生态组合。异步准备通过 `plugin.services >=1.2` 的 OpenSet 和 `contribution-contract.json` 发现贡献；引用由 TS 持有，模块只由宿主封闭导出授权加载。独占 slot、ABI 不兼容或顺序环明确失败。成员或选择变化使受影响组合退休，包含原先为空的集合。旧单适配调用继续兼容；需要生态发现的消费者声明适配契约 >=1.1。

标准 LSP 提供 JS/JSX/TS/TSX 的补全及详情、诊断、悬浮、定义、引用、跨文件重命名和格式化。引擎接收编辑器未保存快照，不写源文件；配置项目与推断项目通过各消费者独立的引用共享。显式指定不兼容 SDK 会报错，不静默回退。四种语言分别声明可选择的 Tree-sitter 高亮提供者，固定来源、摘要和许可证随包放入 `grammar/`。

编译器输入按字节限额并等待有序管道写入完成；引擎暂停读取时，文档分发保留背压。适配器准入失败只在候选进程已结束或尚未创建时，返回带版本的导入释放回执。访客快照为空，不把编译器引用或未完成调用当作持久状态恢复。

已初始化编译器或已准入适配进程意外失效时，所属 stdio 服务等待全部自有子进程结束后退出。宿主按原有有界恢复流程重新准备该上下文及适配器，其他上下文的独立服务继续运行。显式关闭、候选适配拒绝、普通业务错误和请求取消不视为崩溃信号。

源文件同时属于多个配置项目时，由编译器枚举实际图成员，通过原生 QuickPick 选择展示上下文，也可使用编辑器的“选择分析项目”命令重选。显式选择以工作区私有偏好 CAS 保存；偏好名固定为 SHA-256 的 64 个小写十六进制字符，输入依次为 UTF-8 `typescript.project.v1`、一个 NUL 字节、宿主签发且以 `/` 分隔的工作区相对路径原始 UTF-8，不转换大小写或做 Unicode 规范化。导航可临时沿用来源项目的有效上下文，不改已保存偏好。取消有歧义的选择不发布主绑定。配置内容摘要使不同编译进程重启后仍使用单调宿主代次。协作使用公开 `language.lsp 1.6` 上下文登记和交互准备契约；内部引擎不出现在用户提供者列表中，权限确认和资源检查保持生效。

公共协作服务的精确 schema 见 `contracts.json`，调用与权限规则写在 `src/lib.rs`、`native/control.mjs` 和 `native/adapters.mjs` 注释中。适配器必须由宿主签发不可变导出，匹配 ABI、TS 版本和完整文件摘要后，才进入 TS 管理的独立进程。每次挂接都重新核对闭包，拒绝未列入的邻接文件。Node 模块钩子限定普通 require/import 只能加载该闭包及选定引擎，且禁用项目里的 tsserver 插件。原生模块仍具有进程权限；文件系统、VM/eval 及其他操作系统行为不具备 WASM 沙箱保障。

主适配器与贡献模块都使用闭包校验返回的原生规范化入口解析，保留宿主签发的 Windows 文件身份，避免 Node 对原始 verbatim 路径执行 JavaScript realpath 遍历；不通过裁剪前缀或改变封印文件集合扩大访问权限。

构建时使用包含新公开 SDK 的宿主，执行 [英文构建步骤](README.md)。`node build.mjs --stage` 必须使用 Node 24.19.0，固定运行时和 TypeScript 的完整依赖包含在包内；上游授权文本保留在 `licenses/`。访客只通过宿主 `--plugin-cargo` 使用 SDK，不引用宿主源码路径。仅更新插件元数据时保留现有原生归档，跳过 staging 和压缩；`build.mjs` 保留原生工具独立的 0.1.14 标识。

验证命令：`node --test --test-concurrency=1 test/*.test.mjs`、`node node_modules/typescript/bin/tsc -p jsconfig.json`、`cargo fmt --check`。跨仓 Vue 验收需显式设置 `NANOBUG_VUE_FIXTURES` 为 Vue 插件仓库目录；未设置时该测试跳过，不能计为通过。

当前限制：仅准入 TS 5.9.3。导航和编辑限于工作区，外部 SDK/库目标会明确拒绝。配置、extends/引用配置以及各级 package/lockfile 的变化会提升代次；在这些证据不变时替换已安装依赖仍需宿主退休旧配置。已激活项目更换适配器也需要宿主退休旧配置。未知的工作区文件或配置事件可能保守地使其他项目已经签发的结果和预览失效，其绑定与传输仍保留；显式重选展示上下文只使所选源文件的结果失效。消费者快照向量需包含相关未保存依赖。macOS/Linux、其他架构和真实 UNC 共享运行未经验证；真实 Windows 输入法证据仅覆盖已记录的中文候选/提交/取消/Undo 序列。既有 AccessKit Windows 访问性退役路径可在关闭窗口后出现 invalid HWND/COM cannot-unwind 中止；宿主证据保留该上游限制，本次插件支持声明不表示已修复。
